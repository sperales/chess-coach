# Chess Coach 1.5.1 - Review, Variations, Analysis Board and Realtime Scenarios

## Product goal

Turn engine output into an explorable coaching workflow without changing the stored game, duplicating Stockfish integrations or introducing persistent processes.

## Best move in Review

- The `Mejor` control is always rendered between `Anterior` and `Siguiente`.
- It is enabled only for an inaccuracy, mistake or blunder with a valid alternative different from the played move.
- Activating it starts from `fen_before`, applies `bestmove` and displays the resulting position and highlighted move.
- The original review line is never modified. Any normal navigation restores the real position.
- Missing or invalid FEN/bestmove data disables the control without breaking Review.

## Explore variation

- Variation exploration is a temporary mode inside Review and follows the approved mobile design.
- It keeps the game, ply, board orientation and last Review tab.
- The mode shows its origin, selected alternative, evaluation, board, PV position counter, Stockfish line and a deterministic explanation.
- Stored Review PV is preferred. Compatible interactive cache is second; Stockfish is used only when necessary.
- The target line is configurable and normally contains 3 to 5 full moves. Terminal positions may produce shorter lines.
- A legal deviation creates an in-memory branch and requests analysis for the new position.
- Leaving variation restores exactly the reviewed ply and tab.

## Analysis board

- The independent board can start from the initial position, a strict FEN or a Review position.
- Both colors can make legal moves.
- It displays evaluation, best move and principal variation.
- It supports backward, forward, retained branches, reset, board flip, load FEN and copy FEN.
- The analysis tree lives only for the current page session.
- It is available from the hamburger menu as `Tablero de análisis`.

## Realtime scenario training

- Selecting a legal destination submits the move immediately; no Check button is shown.
- A rejected move keeps the scenario active, records the attempt and shows feedback automatically.
- An accepted move is followed automatically by Stockfish's best reply when the scenario continues.
- Alternative valid moves remain acceptable according to the existing pedagogical threshold.
- Nova, Coach Feed, hints and autonomy tracking remain intact.
- Duplicate clicks and stale responses must not advance the scenario twice.

## Shared correctness rules

- UCI remains the internal move format; SAN is presentation only.
- Every move is applied against its preceding FEN.
- Evaluation responses identify their point of view explicitly.
- Mate remains mate and is never flattened into a normal centipawn value for display.
- Missing or incomplete analysis is `null`, never `0.00`.
- Newer position requests supersede older responses.

## Non-goals

- Reconfiguring the full-game Stockfish analysis pipeline.
- Playing a complete game against Stockfish from the analysis board.
- Persisting analysis-board branches.
- Building a generic interactive-analysis framework.
- Adding external APIs, dependencies or persistent workers.
