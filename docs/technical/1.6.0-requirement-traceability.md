## Rollout contract

1. Apply migration 037 before uploading PHP that emits semantic Nova states.
2. Deploy with `training_selection_mode=shadow`.
3. Run bounded backfill from Profile until pending reaches zero.
4. Inspect publication, rejection, duplicate and overlap metrics.
5. Validate `active` only in a controlled environment; it is not enabled by this release.
6. Use `legacy` for immediate functional rollback. New evidence remains intact.

## Honest limitations

- Selection v2 quality thresholds are versioned hypotheses and need production shadow evidence before activation.
- Similarity is deterministic/canonical; semantic embeddings remain outside scope.
- Transfer to later real games is not claimed or scored in v1.6.0.
- Mastery confidence is bounded by the amount and distribution of available evidence.
- Reactive Nova reuses the existing local sprite; conversational intelligence remains future work.
